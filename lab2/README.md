# Лабораторная работа 2. Задача 4

## Условие задачи из методички

Напишите программу перемножения больших матриц. Сравните время выполнения последовательной и параллельной программы на 2, 4, 8 потоках (процессорах).

## Реализация на Go

В данной работе реализовано классическое умножение квадратных матриц $C = A \times B$ размером $N \times N$.

### Особенности реализации
1. **Одномерные срезы:** Матрицы хранятся в виде одномерных массивов (`[]float64` размера $N \times N$). Это гарантирует, что элементы лежат в памяти непрерывно, что критически важно для эффективного использования кэша процессора.
2. **Оптимизация порядка циклов (Cache Locality):** В функции умножения используется порядок циклов **`i -> k -> j`**, а не классический `i -> j -> k`. 
   *Причина:* При порядке `i-j-k` доступ к элементам матрицы `B` происходит с шагом $N$, что вызывает постоянные промахи кэша (cache misses). Порядок `i-k-j` обеспечивает линейное последовательное чтение памяти, что ускоряет выполнение в несколько раз даже в однопоточном режиме.
3. **Распределение нагрузки:** Параллельная версия делит строки матрицы $A$ (и, соответственно, строки результирующей матрицы $C$) на равные блоки между потоками. Это аналог директивы `#pragma omp parallel for schedule(static)` в OpenMP. Запись в разные строки матрицы $C$ исключает гонки данных (data races), поэтому мьютексы не требуются.
4. **Контрольная сумма:** Для доказательства корректности параллельных вычислений программа считает сумму всех элементов результирующей матрицы и сравнивает её с последовательной версией.

## Сборка и запуск

Перейти в папку лабораторной:

```bash
cd lab2
```

### Запуск

Программа принимает два аргумента: `<число_потоков> <размер_матрицы>`.
Для получения заметной разницы во времени рекомендуется использовать размер матрицы от `1000` и выше.

**Запуск с 2 потоками:**
```bash
go run . 2 1000
```

**Запуск с 4 потоками:**
```bash
go run . 4 1000
```

**Запуск с 8 потоками:**
```bash
go run . 8 1000
```

*Для сравнения с однопоточной версией (база для расчета ускорения) можно запустить:*
```bash
go run . 1 1000
```
