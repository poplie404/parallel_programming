# Лабораторная работа 1. Задача 1

## Условие задачи из методички

Написать программу, где каждый поток печатает свой идентификатор, количество потоков всего и строчку `Hello World`. Запустить программу с 8 потоками. Всегда ли вывод идентичен? Почему?

## Реализация на Go

В исходной методичке задача сформулирована для OpenMP и языков C/C++ или Fortran. В данной работе тот же смысл реализован на языке Go.

В качестве аналога потоков используются горутины. Программа:

1. принимает количество потоков из командной строки;
2. создает соответствующее количество горутин;
3. каждая горутина печатает:
   - свой идентификатор;
   - общее количество потоков;
   - строку `Hello World`;
4. главная горутина ожидает завершения всех рабочих горутин с помощью `sync.WaitGroup`.

Дополнительно:

- `runtime.GOMAXPROCS(numThreads)` ограничивает количество потоков процессора, которые может использовать программа;
- `runtime.LockOSThread()` привязывает каждую горутину к отдельному потоку операционной системы, что ближе к формулировке "поток" из задания;
- `sync.Mutex` защищает вывод от перемешивания символов разных горутин, но не гарантирует порядок строк.

Второй аргумент командной строки — размер задачи — поддерживается для единообразия с другими лабораторными работами. В Задаче 1 он не используется.

## Сборка и запуск

### Linux / macOS

Перейти в папку лабораторной:

```bash
cd lab1
```

Собрать программу:

```bash
go build -o lab1 .
```

Запустить с 8 потоками:

```bash
./lab1 8
```

Либо в едином формате с размером задачи:

```bash
./lab1 8 1
```

Также можно запускать без предварительной сборки:

```bash
go run . 8
```

или:

```bash
go run . 8 1
```

### Windows PowerShell

Перейти в папку лабораторной:

```powershell
cd lab1
```

Собрать программу:

```powershell
go build -o lab1.exe .
```

Запустить с 8 потоками:

```powershell
.\lab1.exe 8
```

Либо в едином формате с размером задачи:

```powershell
.\lab1.exe 8 1
```

Также можно запускать без сборки:

```powershell
go run . 8
```

или:

```powershell
go run . 8 1
```

## Пример вывода

Порядок строк может быть, например, таким:

```text
Thread 0 of 8: Hello World
Thread 1 of 8: Hello World
Thread 2 of 8: Hello World
Thread 3 of 8: Hello World
Thread 4 of 8: Hello World
Thread 5 of 8: Hello World
Thread 6 of 8: Hello World
Thread 7 of 8: Hello World
```

А при другом запуске может быть таким:

```text
Thread 2 of 8: Hello World
Thread 0 of 8: Hello World
Thread 5 of 8: Hello World
Thread 1 of 8: Hello World
Thread 7 of 8: Hello World
Thread 3 of 8: Hello World
Thread 6 of 8: Hello World
Thread 4 of 8: Hello World
```

Набор строк должен быть одинаковым, но порядок строк не гарантируется.

## Ответ на вопрос из задачи

**Вывод не всегда будет идентичен по порядку строк.**

Причина в том, что горутины выполняются параллельно, и планировщик Go самостоятельно решает, какая горутина и в какой момент времени будет выполняться. Программа не задает порядок печати. Мьютекс защищает только от некорректного перемешивания вывода внутри строки, но не гарантирует, что первой напечатается горутина 0, второй — горутина 1 и так далее.

Если бы требовалось гарантировать одинаковый порядок вывода, нужно было бы явно упорядочить выполнение и печать, например:

- собирать результаты в массив и печатать их из главной горутины по порядку;
- использовать каналы с ожиданием нужного порядка;
- использовать аналог `ordered` из OpenMP.

В текущей версии программы порядок вывода является недетерминированным.
